# Keys

Compositor binds come from `scripts/setup.sh`. The shell also listens on the bar.

## Compositor

| Bind | Action |
|------|--------|
| Super+A | Launcher |
| Super+Tab | Overview (Hyprland) |
| Super+Grave | Overview (niri) |
| Super+1..0 | Desk |
| Super+Q | kitty |
| Super+E | yazi (float 70%) |
| Super+V | Clipboard |
| Super+C | Close window |
| Super+R | Toggle float |
| Super+B | Pair buds (`services.budsMac`) |
| Super+L | Lock |
| Super+O | Logout |
| Super+, | Settings |
| Super+Space | Keyboard layout |
| Super+arrows | Focus |
| Super+Shift+arrows | Resize |
| Print | Region screenshot |
| Super+Print | Window screenshot |
| Alt+Print | Active-output screenshot |
| Media keys | Play, volume, mute, brightness |

## Bar

Left click opens the panel for that glyph. Right / middle / scroll do the extra verb (workspace jump, volume step, next track).

## Launcher prefixes

Empty query is the rest card. Type to search apps, or:

| Prefix | |
|--------|--|
| `=` | Calculator |
| `:` | Emoji |
| `/` | Wallpaper files |
